# Restaurant Ordering System

A collaborative web application designed to streamline food ordering and checkout for restaurant customers.

## Features
* **Menu Browsing:** Explore delicious starters, mains, and desserts.
* **Interactive Cart:** Add and manage food items seamlessly.
* **Checkout Modal:** Complete orders by providing delivery details and contact information.
* **Responsive Design:** Clean and accessible layout across devices.

## Built With
* HTML5 / CSS3
* JavaScript (DOM Manipulation)
* Git & GitHub for Version Control
